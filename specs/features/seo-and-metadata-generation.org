Automatically generates critical HTML meta tags, OpenGraph data, Twitter cards, and an XML sitemap to ensure optimal search engine indexing and rich social media link unfurling.

* Acceptance Criteria

- [ ] Injects <title> and <meta name="description"> based dynamically on page frontmatter
- [ ] Generates valid OpenGraph (og:title, og:image, og:type) tags for social media sharing
- [ ] Creates a comprehensive sitemap.xml listing all canonical URLs in the documentation tree
- [ ] Automatically generates a robots.txt file pointing to the generated sitemap
- [ ] Supports explicitly defined canonical URL tags to prevent SEO duplicate content penalties
- [ ] Warns the developer during build if title or description metadata is missing
